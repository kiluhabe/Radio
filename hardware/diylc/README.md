# DIYLC レイアウト（C 基板・穴座標プラン）

Raspberry Pi Pico 版ラジオを **秋月 C 基板 (72×47.5mm, [g100189](https://akizukidenshi.com/catalog/g/g100189/))** に手はんだ実装するための、穴座標指定付きレイアウトプラン。`hardware/diylc/radio-rp.diy` が正本（source of truth）で、本書はそこから抽出した内容。

✅ **検証済み（2026-07-22）**：Front/Back 二枚構成（鏡像変換）で全ジャンパ・全ネットを機械的に検証し、ボード寸法・全信号経路とも問題なしを確認済み。ハンダ付け可能な状態。

## 座標系

- 列 (col)：左→右、1〜27
- 行 (row)：上→下、1〜17
- 各セルが 1 穴（2.54mm 中心間距離）。`[col,row]=[1,1]` が基板左上の実際に存在する最初の穴（DIYLC の `PerfBoard` は `firstPoint` ちょうどには穴を描画せず、そこから 1 マス（spacing）内側から穴が始まるため、`col/row` は「エッジから数えた実穴番号」＝物理的にホールを数えた値と一致する）
- 表記：`[col, row]`
- 実機で確認した実穴数：**27 列 × 17 行**
- **四隅はネジ穴（3.2mmφ）で使用不可**。各隅で L 字に 3 穴ずつ、計 12 穴：
  - 左上 `[1,1]` `[1,2]` `[2,1]`
  - 右上 `[27,1]` `[27,2]` `[26,1]`
  - 左下 `[1,17]` `[1,16]` `[2,17]`
  - 右下 `[27,17]` `[27,16]` `[26,17]`

## 前提

- **Pico は USB を左壁面へ**向けて配置（ケース左面から USB を抜き差し）
- **OLED / ロータリーエンコーダ / タクトスイッチ / 音量調整用ポット / MJ-355W はフロントパネル or ケース壁**（C 基板には載らない）
- ⚠️ **アンプ撤去（2026-07-21）**：八ヶ岳クラブ EEHD-4RWA（PAM8403 D級アンプ）は撤去し、アクティブスピーカー前提に変更。M5807PA の LOUT/ROUT はライン出力として、フロントパネルの音量調整用ポット（10kΩ Aカーブ2連）を経由して MJ-355W へ接続する
- C 基板上には：Pico / M5807PA + P20D10B / OLED ケーブル用ソケット / エンコーダケーブル用ソケット / タクトスイッチ用ソケット / 音量ポット入力用 JST-XH / 音量ポット出力用 JST-XH / ステレオジャック入力用 JST-XH / ANT ソケット（暫定）の 9 要素

## 作業手順（DIYLC）

1. **File > New** で新規プロジェクト
2. コンポーネントツリーの **Boards** カテゴリから **Perf Board w/ Pads** を配置し、コーナーのコントロールポイントをドラッグして `firstPoint`→`secondPoint` の差分が 2.8in×1.8in になるよう調整（ホールピッチはデフォルトで 0.1in = 2.54mm）。これで実穴 27×17 になる
3. 四隅のネジ穴を示す目印として、**Electro-Mechanical** カテゴリの **Drill Hole** を四隅の L 字 3 穴（`[1,1]`/`[1,2]`/`[2,1]` など）に配置しておくと部品配置時の衝突が視覚的に分かりやすい（任意）
4. **Pico・M5807PA/P20D10B**：`radio-rp.diy` では **Misc > Label** で各ピンの座標にテキストラベルを置く方式で信号名を管理している（DIP IC コンポーネントではない）。同じ方式を踏襲するか、"Row Spacing" を **0.7in = 17.78mm** に変更した **DIP IC** を使ってもよい
5. **ソケット**：OLED(4pin)・Encoder(3pin)・Push Switch(2pin)・JST-XH各種(3pin) は **Electro-Mechanical** カテゴリの **Pin Header**（"Rows"／"Columns" プロパティで本数指定）で代用し、指定座標へ配置。※DIYLC 標準ライブラリにメス型ソケットのコンポーネントは無く、Pin Header（オス型）で見た目と配線のみ代用する
6. **Connectivity** カテゴリの **Hookup Wire** で「全ネット一覧」に従って配線。色は上記に統一
7. `hardware/diylc/radio-rp.diy` として保存

## 実装時の細かい注意

- ピンソケットは Pico を持ち上げる高さを稼ぐので、下段（Pico の下）の空間で配線を這わせる余裕ができる
- M5807PA は 11.2×11.2mm・2mm ピッチなので、**P20D10B にハンダ付けするときはモジュールが浮かないよう固定**（両面テープでモジュール裏を基板に貼ってからハンダ付け推奨）
- I²C ラインは長くなりすぎないよう配線ルートを決める
- 音量調整用ポット（10kΩ Aカーブ2連）の L/R 入力は M5807PA の LOUT/ROUT から取る。ポットのワイパー出力（L/R）とGNDをステレオジャック入力用JST経由でMJ-355Wへ繋ぐ
- P20D10BのLOUT/ROUTピンをテスターで実測し、DC電圧が乗っていればポット手前に4.7µF程度の直列コンデンサを追加（`docs/parts-rp.md` 参照）
- アンテナは P20D10B の `[13,12]`（ANT）→ `[14,12]`（ANT Socket、現状ピンヘッダで暫定実装）経由で引き出す。他の未使用ピン `[6,14]` `[6,15]` `[13,13]`(RCK) は本当に未接続でよい
